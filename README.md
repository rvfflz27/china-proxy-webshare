## What "Buy China Proxy" Actually Means

A China proxy is a server that routes your web request through an IP address geolocated in China (or sometimes near Chinese network exits, depending on the provider's infrastructure), so that target sites perceive your traffic as originating from inside the country. When you buy China proxy access from a provider like Webshare, you're essentially renting that routing capability on a subscription basis.

There are three main flavors worth knowing:

- **Datacenter proxies**: hosted on commercial servers, fast, cheap, but easier for anti-bot systems to flag
- **Residential proxies**: routed through real consumer ISP connections, slower but far harder to detect
- **ISP proxies**: a hybrid that combines datacenter sped with residential ISP registration

For most use cases, the answer to "which one do I need?" depends entirely on the target site's tolerance for non-residential traffic.
